## Contract and safe consumption

Two new tools:

- `get_target_window_topology_capabilities {}`
- `get_target_window_topology {pid, window_id, request_nonce}`

The consumer checks the actual negotiated producer/schema/source/scope/read-only limits, exact target and nonce, sample epoch/sequence, all-layer CG A/B stability and counters, strict AX query results, root/overlay object tokens, visibility and frame proof. Missing tools/fields, query errors, unknown Space metadata, incomplete arrays or unsupported evidence refuse input; there is no stock-RPC fallback.

V2 additionally requires successful actual root-role/subrole queries and ordinary classification: only `AXWindow + AXStandardWindow` is admitted. Dialog/SystemDialog/Sheet, missing/unsupported and unknown root subroles are unknown, not defaults. Even with an unchanged CGID/object token, non-cancel topology errors invalidate old Surface refs. V1/v2 consumers and producers reject each other's schema/capability. The window-ID schema uses typed `u32::MAX`, retaining IDs through 4294967295 rather than narrowing to signed i32.

`scope=target-ax-closure-cg-all-layers-v1` and `global_topology_complete=false` are always explicit. Target AX closure is never converted into the old global inventory `complete`. Cross-process ownership, absence of other applications' blocking UI and full desktop operability are not claimed.

The producer uses strict read-only CG/AX calls. It does not enable Chromium accessibility, capture images, register actuator elements, read titles/values, activate windows or inject input. Core mapping explicitly classifies the target query as private observation, keeps policy deny effective and gives it Window (not Desktop) scope. Trusted internal transport metadata is sanitized before strict public-argument validation.

Retained CFEqual identities are bounded observation tokens, not OS lifecycle IDs or actuator refs. The cache has at most 16 exact targets, each one root plus at most 32 visible overlay references; entries expire after 180 seconds, replacements/evictions release retains, and daemon epoch changes invalidate continuity. AX path is a relationship label, not object identity.

Each query is bounded to 4096 CG rows, 2048 AX nodes, depth 40, 32768 queries and a 6000 ms checked native deadline, with 0.2 second AX messaging timeout. The caller deadline is 6500 ms. An already-running synchronous OS query cannot be forcibly cancelled by JavaScript; late capability completion never starts another RPC.

## F024 opt-in isolated topology host/client

Two macOS-only early entry points bypass all normal startup assembly:

- `topology-readonly --state-root ABSOLUTE_ROOT --pid PID --window-id CGID`
- `topology-readonly-call --state-root ABSOLUTE_ROOT --pid PID --window-id CGID --tool get_target_window_topology_capabilities`
- Target call adds `--tool get_target_window_topology --request-nonce UUID` instead.

These are source-authored command templates, **not executed or deployment-approved**. Use an independently identified local bundle/binary, never replace the original com.trycua.driver. Do not use ordinary `call` for this isolation mode. No HOME/PATH changes or inherited internal-worker configuration are required. Non-first/repeated mode tokens, unknown flags, bypass/unrestricted/manifest approval/worker environments and arbitrary JSON/session arguments fail before ordinary startup. Only fixed private root `topology.sock` and `topology.pid` are created. Existing entries are refused, never unlinked. No automatic cleanup: retain artifacts, stop only the verified private process, inspect and clean explicitly; every new launch uses a fresh root.

The existing absolute root must be current-UID owned mode 0700, with no symlink path components and only trusted ancestors (root-owned sticky temporary ancestors allowed). Its `policy.yaml` must be an owned private regular file. Explicit managed policy remains a ceiling but must also be an owned private file directly inside that root; conflicting/outside policy paths refuse. Suggested ceiling:

```yaml
allow:
  tools: [get_target_window_topology_capabilities, get_target_window_topology]
```

Only the two production tools are registered, not a filtered full platform registry. Canonical per-call standard authorization/policy/hard invariants remain; private observation is Routine under standard, so this does not promise an approval card for every read. The exact positive i32 PID/full-u32 CGID is fixed at startup; a different target refuses before any AX/CG query. Only pure `metadata` and `call` transport methods exist. There is no list_windows, capture/input/browser/profile, SDK assembly, history/recording tools, PiP/overlay/update/telemetry/log initialization, permissions gate, shutdown/revoke or public session selection. Core's inactive recording/session hooks do not start capture. Missing AX trust fails without prompting or requesting Screen Recording.

The dedicated client verifies mode, daemon contract versions, private root inode/UID, daemon PID and bound target, plus endpoint identity before and after each call. It checks producer/schema/source/scope and positive completion/root/CG flags; unknown/error/malformed responses exit nonzero. Output is only a fixed numeric/bool/enum diagnostic projection, including closed native unknown reasons, not raw text/rows/private content. This bootstrap validation is not the complete Harness topology parser or T2/T3 admission.

One connection/probe at a time, 4096-byte request frames and five-second read/write deadlines bound transport occupancy. The existing core client has a 120-second response deadline; neither it nor the native six-second checked deadline forcibly interrupts a synchronous AX/CG call. No retry/replay is added. A same-UID malicious process can still race path replacement or forge local evidence: pinned directory/rechecks/0700 do not claim cryptographic peer authentication or full race freedom. Absolute Unix socket bind has a residual rename race; failure does not unlink another process's files.

No user configuration/history/PiP fallback is read. Configuration is solely the explicit private policy; no config/history/log file is initialized. Production defaults and all normal entry points remain unchanged. A compliant fresh exact numeric target identity and manual AX authorization are prerequisites; absent identity/permissions is a stop, not permission to add inventory/title guessing or system prompts.

Thirteen new `topology_readonly` unit tests cover arguments/environment, mode placement, private paths/symlinks, no overwrite/deletion, metadata mismatch, actual production registry capability/zero-query negatives, malformed frames/results, safe unknown projection and policy deny. They are authored, not run here. Test role may privately check/test/link this new exact patch without launching it; F022 historical results must not be promoted to current F024 evidence.
