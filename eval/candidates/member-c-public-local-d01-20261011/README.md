## 实例准备与日期规则

在仓库根用已有Python 3.9+且具备`Asia/Shanghai`的IANA时区数据运行。工具只调用标准库，但时区数据库是环境前提；例如Windows缺少该数据时，须先按环境准备/安装授权规则补齐。本工具创建参数默认值时就读取时区，因此显式传`--run-date`也不能绕过时区数据缺失。本PR未新增依赖或修改冻结工具字节。

```text
python3 eval/candidates/member-c-public-local-d01-20261011/prepare-instance.py --manifest eval/candidates/member-c-public-local-d01-20261011/medical-manifest.v1.json --family M01 --variant v1
```

M02必须先由操作者核对当前可见表头，再传入具体`--target-date YYYY-MM-DD`；v1只能星期三、v2只能星期五。准备工具仅校验星期，**不证明日期确实在页面范围**，初态人审仍必须完成；调查中的2026-10-14不是未来长期固定输入。

M03/CP03必须传入`--output-file`，值为本Run新目录内尚不存在的Windows绝对`.txt`路径。工具不访问Windows文件系统，不能以工具成功代替输出不存在/路径授权检查。CP03可传`--run-date`与`--preferred-date`；未指定preferredDate时展开为运行日后3天内第一个工作日，只是咨询期望，不是已获预约或对节假日营业的承诺。

准备结果中的`executionRelease=blocked_pending_windows_preflight`必须保留。本轮校验只证明合同可消费、日期与路径可展开，不是准备工具替代Host准入。
