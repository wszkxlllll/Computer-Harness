# 跨窗口运行器任务输入

## CW01 · Easy：社区通知变成一份易读备忘录

**场景：通信、日程与个人资料 / 社区服务。** 价值：用户不必在多个软件中抄写，适合看小字困难或不熟悉文档操作的人。先测纯原生跨应用，不依赖网站可达性。

### 你准备什么

- WPS 打开新的 `CW01-社区通知.docx`，粘贴下列合成通知并保存。合成素材可公开展示，不代表真实活动。
- 记事本打开新的空白编辑窗口，不用你的已有笔记；若记事本是多标签版本，告诉我是否可单独开新窗口。
- 手动确认 WPS 通知完整显示、记事本能正常输入和保存到测试文件夹。不要先生成答案。

```text
实验用社区通知（非真实活动）
主题：手机使用小课堂
时间：2026年10月10日，星期六，上午9:30至11:00
地点：实验社区活动室二楼201室
参加者：社区居民，可由家人陪同
携带物品：本人常用手机、眼镜（如需要）
费用：免费；不要求携带银行卡，也不现场收费
报名：本次实验无需报名
提醒：请提前10分钟到场；如上下楼不便，请提前向工作人员询问无障碍通行安排。
```

### 完整 Goal

```text
请阅读已打开的 WPS《CW01-社区通知》，把它整理成一份给看小字困难、不熟悉手机操作的长者使用的中文备忘录，在空白记事本中写好，并保存为新的“CW01-活动备忘录.txt”到我指定的测试输出文件夹。
把什么时候、去哪里、带什么、是否收费放在最前面，用短句和分行，不使用术语。明确标注这是实验通知，不是真实活动；不要把“可以陪同”写成“必须陪同”，不要编造电梯、无障碍通道或报名电话。写好后回到 WPS 核对原通知，再返回记事本确认并保存。只操作这两个测试文档，不覆盖已有文件，不发送给任何人。完成后用中文简述结果和保存位置，不要把尚未保存说成已保存。
```

### 人工验收

- WPS → 记事本 → WPS → 记事本确实完成，不是仅在回复里说“已整理”。
- 新文件可重新打开，时间、地点、携带物品、免费/无需报名与原通知一致；合成标识保留。
- 短句、关键信息前置，没有把建议变成强制要求或编造无障碍设施。
