## 并行分工与合并修正

1. CUA：合并 Windows Surface/SDK 合同与 Mac 注册窗口截图、像素坐标、DOM 指纹和真实输入焦点；只使用当前激活 Surface 的浏览器绑定，不回落到启动时旧绑定。Surface 切换清理输入状态。
2. 风险与 Runtime：保留失败结果和不完整响应拒绝执行；搜索/地址栏低风险例外须与当前观察、会话、Surface 和实际控件绑定，组合按键或证据不完整继续正常风险审查，不能仅信模型的“搜索/导航”描述。
3. Web：融合语音、偏好、跨窗口和 Surface 提示，保留连接 12 秒反馈、恢复清理和单一刷新错误来源；避免重复目标选择控件。
4. Host/App-runtime/CLI：Mac 受管浏览器默认选择保留，Windows 仍用 Edge；保留远端 profile 生命周期与清理。GLM 保留 `low/high/max` 档位和本地 8192 输出预算/90 秒 Host 请求期限；旧 `disabled` 配置在应用边界归一为 `enabled`，避免已观察到的 400/1210。不关闭风险审批、不重放未知结果动作。
5. 跨包工具目录：全 Run 禁用坐标点击与新跨窗口功能存在冲突。整合后按当前 Surface/能力约束：受管浏览器不能降级原生坐标点击，切到原生窗口/桌面后保留适用工具；反向切回再次收紧。

审查中发现并修正：地址栏一次输入许可会跨 `Ctrl/Cmd+F` 等快捷键残留；快捷键需区分 Windows/Linux Ctrl 与 macOS Cmd/Meta。未知结果后不继续沿用输入许可；Tab 新焦点需要新观察，不能复用旧控件引用。

独立 5.6 sol medium 终审进一步要求：导航豁免目录必须 `complete`，不能接受缺少截断标记的 `partial`；地址栏待验证意图绑定 session/Surface/browser，在快捷键后和 type 前读 UIA/DOM 正向验证，观察到页面焦点即失效；受管浏览器 UIA 内容元素没有完整 DOM 的唯一等价目标时拒绝原生点击。以上不能由模型文字声明或“快捷键 completed”替代。

可用性限制：若平台驱动不能提供完整、唯一的真实地址栏焦点/身份，地址栏 type 返回 `BROWSER_CHROME_FOCUS_UNCONFIRMED`，不盲目输入。可使用受管浏览器起始网址；普通网页输入仍需 DOM 实时焦点校验。此严格路径仍需各平台实机验收。
