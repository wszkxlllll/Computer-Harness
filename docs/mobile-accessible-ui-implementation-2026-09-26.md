状态：2026-09-27 已按成熟 App 参考重做实际 Web 界面，移除绿色主题与宣传式文案；最终代码、布局复查与测试见文末。保留审批修复与功能实现。尚未通过真实手机读屏与真实应用任务验收。语音只预留能力接口。本轮不发布公网，不发送真实消息，不擅自 commit/push。

## 分工与边界

- Luna max：Runtime/Host 审批证据与失效恢复及测试；不得关闭 Guard 或用宽松全图像素阈值代替安全判断。
- Luna max：手机界面、截图 viewer、偏好设置、无障碍交互、语音占位合同及组件测试；电脑仅连接管理。
- Sol medium：两部分完成后统一审查安全、合同一致性、回归及 UI 无障碍风险。
- 主 Agent：合同协调、独立验证和交接记录。已存在的点击后前台失配另行保留，不宣称随审批/UI 改造消失。

## 验收目标

1. 标准/大字简洁切换与独立字号、高对比度、减少动画；偏好不改变 Guard。
2. 运行、审批、结果、错误和断连信息清晰，完整结果不被截断；状态基于回执，不基于按钮点击猜测。
3. 审批准确绑定请求与证据，区分模型声明和事实；审批过期不让模型无休止重复申请，未知输入不自动重放。
4. 截图鉴权不变；等比显示、缩放、拖动、按钮替代手势，查看中不自动替换画面；最新截图不冒充审批依据。
5. 语音默认不可用，无自动录音、播放、付费调用；后续接入有真实能力与调用边界。
6. 窄屏及放大布局、键盘/焦点、状态通知、测试与构建通过。模拟测试不替代手机读屏与真实电脑任务验收。

### 审批语义修正要求

用户补充明确：不能把“截图微变→拒绝→模型再次申请”改成另一种重复确认流程。设计目标为展示请求前获取证据，用户对该请求绑定的具体动作作一次有效批准；不是先批准，再因光标变化强制批准第二次。批准不能推广到后续相似动作，亦不能覆盖目标窗口/几何/会话失效或用户纠正。最终以实现和测试结果说明哪些动作可继续、哪些缺乏证据，不能用“已停下”冒充循环问题完全解决。

本轮源码核对：Guard 对 declared high-impact effect 直接审批；target/summary 关键词信号进入 semantic_review，在没有 assessor 时保守回退为审批。这与“所有关键词都直接要求审批”不完全相同，但确实能产生用户看到的保守审批。先修具体动作批准的有效消费，不增加针对某个网站/应用的关键词豁免，也不暗中关闭 Guard。

## 用户补充：个性化入口

显示偏好与助手偏好分离。显示偏好只由 UI 消费；助手偏好首版为小型、版本化、白名单字段的本机设置，例如回复详略、解释程度及语言，支持恢复默认。不采集疾病/年龄等敏感画像，不自动从截图推断用户特征。

若尚未通过 Host 接入 Context，界面必须明确标注“仅保存，尚未影响助手回复”。后续接入时由 Run 创建入口显式传递、Host 校验、Context 编译器按固定低优先级区块消费；对该 Run 固定快照，记录生效版本，不每轮重复追加。用户当前明确要求优先，安全策略与审批不受其覆盖。手机本机保存不意味着跨设备同步，不把未经校验的自由文本当 system 指令。

## 交付记录

### 已确定的实现合同（仍待测试）

- Runtime 在需要审批时、发出审批事件之前，获取新观察；原动作决策帧仍保留为 decisionObservationId，实际执行帧单独记录。
- 同一审批只授权同一个 ToolCall；不缓存“以后同类动作都批准”。新鲜证据通过 `preview.evidence` 投影给手机，其 assetId 仍通过现有鉴权截图接口读取。
- 批准后的同一次执行不再依赖全图字节完全相等，也不重复调用 Guard。会话/坐标空间/几何失效、用户控制指令和驱动输入前保护不能被跳过。
- 这是一种“用户核对具体动作和证据后授权”的模式，不等于系统已证明页面内容或键盘焦点永不变化。对键盘动作明确提示人工核对；无法核对时不应批准。证据截取后到输入之间仍存在环境变化风险，不能宣称安全问题被完全消除。
- UI 的“审批已处理”和“GUI 动作已完成”是不同状态；结束/失败状态只由实际回执驱动。

### 集成审查重点

审批微变不循环、真正失效阻止执行、重复命令不重复执行、用户纠正/Abort 竞态；审批精确截图不与最新截图混淆；旧请求返回后的按钮失效；隐藏或卸载 viewer 后焦点恢复；大字模式下按钮/结果不被固定底栏遮挡；个性化和语音设置不暗中启用网络或模型调用。

完成后在本文补实际改动、验证命令/结果和未验证项，保持 [设计提案](./app-ui-design-proposal-2026-09-26.md) 的设计与实现状态明确区分。原实机缺陷证据见 [失败复核](./mobile-real-run-audit-2026-09-26.md)。

## 最终代码交付与验证

- 手机：标准/大字简洁布局；独立字号、高对比度、减少动画；任务/个人偏好导航；完整结果与按需展开过程。
- 截图：站内鉴权 viewer，等比展示、缩放/平移按钮及手势；查看时固定资源，有新截图只提示；旧请求更新/消失清理；modal 背景 inert，键盘循环和关闭/卸载焦点恢复。
- 审批：显示该请求绑定的证据及具体动作；模型说明明确未核实；证据缺失/图片加载失败不得批准需要视觉核对的操作；全屏打开可选，不强制多一次审批。远程命令处理回执与 GUI 成功分开表述。
- 个性化：版本化、白名单、浏览器本地保存与恢复默认；助手偏好未接入 Context，界面明确说明。
- 语音：`App` 可显式注入 `VoiceCapabilities` 的 `readAloud` / `transcribeOnce`，默认没有实现。当前只在偏好页提供可选能力测试，转写不自动提交任务；不录音、不调用浏览器语音服务或模型。
- 电脑端继续使用连接管理页，不引入任务工作台，不虚构停止服务 API。
