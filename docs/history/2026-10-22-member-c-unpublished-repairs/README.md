## 本 PR 的修复范围

### 产品：wire 预算、Context 与可见正文

产品差异涉及 20 个文件：10 个生产代码、7 个既有测试、3 个说明文档。

1. **发送前 wire 成本反馈与有界收敛。** Provider 完整投影后给出结构化成本；Runtime 可让 Context 降低本次文本选择目标，每个 decision 最多重编译八次。配置上限不变，不增加真实模型请求，不重放 GUI。必需内容仍超限、反馈无效或收敛耗尽时明确本地失败。
2. **保留必要上下文与 continuation 配对。** Goal、用户纠正、当前观察、最近 GUI 调用与结果，以及最新 reasoning 工具轮次和配对结果保留在必需内容下限内。
3. **准备期中断与状态更新。** 准备后重新处理取消、用户纠正及收尾变化，避免继续发送旧上下文。
4. **有界可见正文 `visibleDocument`。** 与交互控件、原生表格路径分开，提供经证明可见的完整正文块及原生滚动区域；最多 32 块、总计 4800 字符、每块 480 字符、4 个滚动区域。部分可见、过长或超预算的块整体省略，不能截成伪原文。
5. **当前来源与几何绑定。** 正文对应当前 observation／session／surface／page URL；desktop 投影要求精确前台浏览器身份、稳定完整 inventory、可信几何、viewport 与非遮挡证明。仅有限兼容纯二维平移及透明／柔和阴影，未知绘制仍保守省略。缺失证据不等于页面没有正文。

main 已有的多行输入审批、明确受管浏览器起点的一次首次聚焦、变更完成声明要求本 Run 动作与新观察三项实现不重复叠加。原旧工作树的历史修改不整体覆盖 main，也不回迁旧 Provider usage／grounding／Monitor 策略。

### Host：显式启用的实验工具，不修改产品默认装配

[可复用模块](../../../scripts/host-foreground/README.md)包含当前来源读取、Ctrl+F 弹窗准入、精确原生区域与命中、Driver 点采样合同、派发前复核、可写多行文档证明和专用编辑器生命周期，以及原有六个行为测试文件。多来源通用接口保留，四题浏览器限定策略作为独立 profile；未将本机启动器、模型凭据读取器、桥、队列或旧 claim 搬入公共目录。

这些模块是此前实际使用的 Host 修复，不等于已接入默认 Host 启动流程。第二批的 no-editor 分支明确禁用 editor 角色；未知来源、窗口、区域和副作用仍拒绝。读取 Win32 证据与最终 Driver 调用不是原子 OS 门控，不宣称消除所有竞态。

### 原生 Driver：按现有补丁目录交付

[Windows ComboBox 列表补丁](../../../patches/cua-driver/7852ab1-windows-owned-combo-popup.md)基于 CUA 候选 `7852ab1983b60c0ce581b8736c9da13eaf04640a`，涉及四个 Rust 源码路径。它用当前焦点／捕获父链与 `GetComboBoxInfo` 的精确关系证明非激活列表归属，保留原派发与事件前后检查。附完整 MIT 许可，不包含二进制，不改变锁文件，不代表上游已发布。

两批均为 Ark `deepseek-v4.1-flash`，真实请求 enabled＋low，max output 16384，context 16384／24576，单轮墙钟上限 30 分钟。没有渠道切换或失败轮补跑。费用均未知，正式 evaluator 未运行；业务复核是助理依据轨迹、截图和独立公开来源的语义复核，不是可信人审，也不是受控 A/B 或稳定成功率样本。

- **A：窗口绑定 foreground。** 受管浏览器，`windowSwitch=off`、`windowHandoff=off`。原记录为三轮业务复核通过、一轮不通过、四轮未交付；保留原结论，不用第二批的新增发现重评分早先记录。
- **B：native desktop 全前台。** `managedBrowserCompanion=true`、无 `windowTarget`，31 次业务观察全为 desktop，1280×720 physical。产品 companion 要求 `windowSwitch=opened-windows-v1`；Host profile 明确拒绝 `switch_window`，handoff off，输入仍限本 Run 专用官方浏览器。不是任意应用输入许可。
