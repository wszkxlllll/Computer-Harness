# 手机与电脑 App 式界面实施依据

更新：2026-09-27。用户已否定绿色主题、方框堆叠及把设计意图写到界面的做法，要求参考成熟 App 并继续完成实际代码。此前生成图不作为验收依据。实际实现与测试见 [实施记录](./mobile-accessible-ui-implementation-2026-09-26.md)。

## 成熟 App 参考

按用户要求，视觉设计只以成熟应用及项目真实需求为依据，不采用 skill 的视觉建议。

- [Things 官方功能展示](https://culturedcode.com/things/features/)：任务列表、细节按需展开、新建入口。只参考交互层级，不复制品牌资产，不加入本项目不存在的待办功能。
- [Apple 提醒事项](https://support.apple.com/en-ie/guide/iphone/iphc7880ecd6/ios)：列表和分组选择的系统控件习惯，不以宣传页作为产品模板。
- [Telegram 媒体查看](https://telegram.org/blog/new-profiles-people-nearby)：直接查看图片、返回原任务的交互连续性，不引入社交功能。

## 当前设计选择

白色/浅中性底色、深色正文、少量蓝色操作强调。去除绿色品牌区、营销大标题、彩色侧边条、重复边框和解释段落。页面只出现任务、设置和操作信息，不出现“像说一句话”“少而清楚”等设计理念。

| 页面 | 内容与职责 |
| --- | --- |
| 手机首页 | 新任务输入、操作窗口选择、当前任务及最近任务；不虚构进度或对话 |
| 任务页 | 实际状态、目标、截图、完整结果、暂停/继续/结束及允许时的纠正输入 |
| 审批 | 具体动作、尚未核实的模型说明、请求绑定截图、同意/拒绝；技术参数按需展开 |
| 截图 | 站内全屏查看、等比缩放、平移与按钮替代手势；点击图片不发送电脑输入 |
| 设置 | 标准/大字简洁预设、独立字号/对比度/减少动画、个人偏好、语音能力状态 |
| 电脑 | 二维码、配对确认、授权设备列表与撤销；不做第二个任务工作台 |

大字版共用同一视觉体系，不把每个控件加粗边框。模式切换一次设置布局与字号，后续仍可单独调整；自定义组合如实展示。按压/展开动效仅用于反馈，减少动画时功能完整。

## 与当前架构的对应

- RunSnapshot、useRunFeed 提供真实状态；按钮由 capabilities 控制。
- useRunCommands 复用 commandId 去重和 accepted/applied/rejected/outcome_unknown；“审批已处理”不能显示为“消息已发送”。
- Computer 审批在请求前采图，preview.evidence 关联 assetId、观察时间和视口；requiresVisualReview 不依赖预览是否成功生成。需要证据却无法加载时不放行。
- 截图通过现有鉴权 runAssetUrl 提供。viewer 固定打开时的资源；新截图提示但不自动替换。请求变化时旧批准按钮失效，关闭后同步状态。
- 最新普通截图不是视频，没有手机立即触发采图的 API；不能用 Run 更新时间冒充图片采集时间。
- 个性化为白名单、版本化的浏览器本地设置；助手偏好尚未进入 Context，页面明确说明，不暗中修改任务/审批规则。
- 语音为显式注入的 VoiceCapabilities，默认没有实现；无默认录音、朗读或模型请求。
- 电脑连接 API 不提供停止 Host 服务，页面不能显示一个虚假的可用按钮。

## 不变的安全与可用性边界

批准只针对一项请求，不成为未来类似动作的通行证。人工核对截图不等于机器证明收件人、焦点及之后的页面内容不变；失效窗口/几何/会话及用户纠正仍能阻止执行。原点击后前台失配问题保留，见 [实机失败记录](./mobile-real-run-audit-2026-09-26.md)。

读屏语义、焦点管理、键盘和非手势替代操作适用于所有模式。截图像素无法通过一个 alt 文本变成可理解的无障碍证据；无法核对时应明确允许拒绝/停止，不声称无障碍设置解决此限制。

## 验收

使用实际构建页面及模拟 API 截图，不再用概念图代替实现。覆盖正常手机、320px 小屏大字、200% 文字放大、审批/旧请求、图片查看、设置及电脑连接页。检查溢出、遮挡、焦点和错误状态。自动化通过不等于真机读屏或真实任务完成，未部署版本不得宣称已在公网页面上线。
