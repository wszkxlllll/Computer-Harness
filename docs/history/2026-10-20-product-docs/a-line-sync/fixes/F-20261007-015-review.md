retained cache guard 持有 AddRef；新代码先 is_uia/nonnull，借用 IUIAutomationElement 使用 ManuallyDrop，防止 early return/panic 时接口与 guard 重复 Release。pattern/cast 结果是各自拥有的 COM reference，guard 在整个 worker 内保持存活。该生命周期是静态审查，不是 Windows 内存安全现场验证。

已有 fg_bypass 用 RAII DisabledHwndGuard，正常或 panic unwind Drop 时尝试恢复先前 EnableWindow 状态；不扩大修改既有 shield。read error 可零 SetValue/fallback，但已执行 overlay 与暂时 EnableWindow shield，不是零 GUI 变化。WPF 自 foreground 的已有限制仍在，本批不声称解决焦点或所有 GUI 副作用。

HRESULT 只把直接 GetCurrentPattern 的 UIA_E_NOTSUPPORTED 映射为不支持；cast E_NOINTERFACE、空 pointer、stale、timeout 与任意其他错误拒绝文本派发。Microsoft 对 [UI Automation error codes](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-error-codes) 定义 UIA_E_NOTSUPPORTED 为 provider 明确不支持，不能把所有失败当成这个类别；[GetCurrentPattern 文档](https://learn.microsoft.com/en-us/windows/win32/api/uiautomationclient/nf-uiautomationclient-iuiautomationelement-getcurrentpattern) 仅规定成功 S_OK/失败 HRESULT，未授予 all-error fallback 合同。
