Qwen HTTP client 存在独立复现的截止与取消缺口。Astra medium 以内存 fake HTTP 验证：忽略 Abort 的 headers/body 在期限后仍成功返回，Run 取消后迟到 body 仍返回，永久 pending fetch 不被本地期限结束，直接 client 的预取消调用仍发起一次 fetch。合作的超时拒绝被标为 retryable true / same_input，不能据本地结束认定远端请求已停止。协调方也以 source 导入和 fake body 独立复现迟到成功及直接 client 预取消派发。

这些证据未调用真实 HTTP，不代表历史 GLM 延迟原因。Adapter 的入口取消检查与直接 HTTP client 合同分别核对，不把后者缺陷说成所有 Adapter 请求均会预取消派发。

## 实施范围

F011 独审闭环后，由唯一 6.1 Sol medium 作者修改 packages/provider-qwen/src/index.ts 和 index.test.ts，另一位 6.1 Sol medium 独审。单个 monotonic 总期限覆盖 fetch 和 body，以独立取消竞争结束不合作异步等待；序列化后、派发前及返回前检查取消和期限，保留首次取消来源及 Run 原 reason。迟到结果不得成为成功或触发第二次请求，迟到拒绝保持被观察，timer 和 listener 完成后清理。

本地超时改为非 retryable / feedback，防止远端结果未知时自动重发。保留默认 240000ms 与 Host 180 秒配置、既有预算和风险控制；不消费模型额度，不构建共享 dist，不切换运行服务。

## 验收与后续

唯一作者完成约定的总 monotonic deadline、Abort race、派发及返回边界检查、首因取消 reason 和 finally 清理；timeout 改为非 retryable / feedback，普通 network/HTTP 策略保留。作者报告42项与包级noEmit通过。独审首轮实际作者42+独立13共55项通过；持久归档独测只改一行 import 后，在正常仓库配置实际再次55/55，tests37ms、总355ms，包级noEmit exit0，三文件前后hash一致。root另跑作者42项通过，tests28ms、总356ms；轮次不累计。
