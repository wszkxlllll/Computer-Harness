新有限纯进程交叉验证方案可能提供WindowServer与NSWorkspace一致性bool，但需要另行明确冲突元数据权限/合同/独立审查；不是现有接口，不能现在直接调用，也不授予TextEdit输入。当前更短的可区分准备方式是由用户在同一Mac明确选择已受控空白文稿、保持前台且不切Terminal/Codex，再由既有后台通道一次F0504查询。此方式仅准备，不要求人代输入/保存，不先证明缓存问题，也不降低守卫。
