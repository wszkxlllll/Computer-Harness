## 冻结后顺序

1. 核指纹、补丁、镜像、锁及正式源码，追踪发现→保留对象ref→激活→后验调用链；确认无stock全局标题枚举/CocoaAllWindows。确定真实测试过滤器/数量，再独占reserve。
2. 私有目标目录check、新正反例及旧unique/selected/topology/授权回归，再link记录binary/hash/signature。Allow正例必须命中actor；拒绝策略必须合法加载且零查询/激活，不能拿解析失败当拒绝。
3. 新私有root/policy，一次受控bootstrap：完整唯一识别→短命ref→同对象再验→写前消费→一次激活→fresh后验。unknown/失败停止，不重放写操作，不输出其他文稿标题/路径。
4. 独立许可的真实v2拓扑核target/root/closure/Space/前台，保留对象延续至最终核验；不能用同PID/CGID或nonce替代连续性。事务结束/epoch改变后ref失效，不把数字身份当生产Run引用。
5. 另核生产session/capture/input、device/task/Run作用域、独占桌面和输入前前台守卫，fresh精确截图确认正文为空。有限准备成功不是生产socket/输入许可。
6. 保存Surface成立后，原T2三轮整段六行含末LF一次输入、GUI UTF-8唯一新文件保存、关闭重开、只读字节比较；T3真实纠正旧请求失效、跨应用切换、保存重开。T1稳定性/变体和控制/真人手机门槛保留。

## 必须核的反例

- 同PID/CGID却AX对象替换、同名替换、app重启、Space/几何变化或前台被抢：accepted激活不等于核验通过，不能授输入。
- 发现许可不代授激活；只有激活许可而读取被拒绝不能进actor；旧unique/selected、desktop/app-all-windows许可不代授；topology/capture/input分别核，managed/user deny优先。
- 排队/重新识别期间取消及写前TTL到期均零写；原生写已开始后取消/超时必须准确报告可能已激活或unknown，不能说零副作用或重试。失败引用不复活，并发消费只有一次写序列。
- 未知title、坏项、重复、超限、未完成枚举不能filter成唯一；后验不能重新挑另一个同名对象。无关已识别不匹配文稿最小化不应误伤本任务，但它的身份缺失仍不允许猜唯一。
