上一目标轮官方CUA现场证据确认身份bootstrap缺口，本轮查固定F026源码并由6.1 Sol medium独立只读调研；没有写业务、运行原生query/cargo/GUI或权限操作。修复线程实际active/inProgress turn01a10773-64f3-7413-94ef-11ff6fd93592、wait cursor187→190核实，非仅相信文档锁。

主核：NSRunningApplication::runningApplicationsWithBundleIdentifier已被上游私有running_pids_for_bundle使用，可限定bundle查询，但后续reconciliation_pid用.find，不能拿来证明唯一性。focused_window_id_of_pid只读AXFocusedWindow映射CGID，不证明唯一普通root/owner/可见性。ListWindowsTool先全局枚举title后filter，不符合限定发现边界。

独立调研：可新建有限TextEdit应用范围模式，以NSRunningApplication按固定bundle仅读PID/终止/身份；严格限定PID的AXWindows及真实AXWindow+AXStandardWindow，拒绝任何读取失败/坏项/重复/不映射/多窗，不能跳过坏项变“唯一”。依赖支持按确切ID的kCGWindowListOptionIncludingWindow，可只解析数值owner/layer/visible、不读title/appname。再次实例/窗口采样核连续性；没有输入、激活或launch，失败闭合。

不得复用list_running_apps、windows普通高层helper、最大面积/z挑窗或copy_ax_windows失败为空/滤项合同。成功只返回freshPID/CGID，非完整拓扑/空白正文/无弹层/输入权限证明；之后仍需既有精确host重新绑定。新操作必须显式standard/private observation及私有policy，不伪装exact-window，也不借发现引入全桌面权限。缺AX只读拒绝，无prompt/录屏/普通serve初始化。

独立验收建议：唯一实例/唯一普通窗成功；0/多实例、0/多窗、dialog/隐藏/最小化、AX拒绝/丢行/重复/privateSPI失败、CGowner不符、A/B窗口重建/进程重启。负例零输入/激活/启动应用，输出无标题/value；注入数据离线测试不能代现场数字身份成功。当前F026没有此入口，不提供猜测可执行命令。

结果交给修复方纳入方案/独立审查；当前没有新冻结产物或构建占用。完整T1复验/变体、T2/T3及控制/手机边界保持，不把发现路线当完成。
