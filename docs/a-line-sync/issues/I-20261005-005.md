## 主审查发现：API合同混淆，优先实质修正

本机CGWindow.h 153-157将IncludingWindow定义为把relativeToWindow纳入列表；248行“only specified window”仅在CGWindowListCreateImage的图像合同说明。当前cg_identity注释把这种单窗图像语义带入CopyWindowInfo列表函数，不能证明会返回只含一个对象。

苹果[optionIncludingWindow官方文档](https://developer.apple.com/documentation/coregraphics/cgwindowlistoption/optionincludingwindow)明确需要与OnScreenAboveWindow或OnScreenBelowWindow结合才有有意义结果；[CopyWindowInfo](https://developer.apple.com/documentation/coregraphics/cgwindowlistcopywindowinfo(_:_:))的relativeToWindow是选择其他窗口的参考。故当前单独1<<3 + unique_count==1的exact查询假设缺正确API合同支持。这是源码可确认缺陷方向，尚不证明本次返回0还是多。

本机SDK 184-194提供CGWindowListCreateDescriptionFromArray：仅针对传入window IDs返回字典。优先以单个已验证AX数字CGID构造正确encoded array，再一次精确description查询；不采用above/below全窗列表再过滤、不绕过唯一性/owner等检查。须核CGWindowID特殊数组编码（不是盲用CFNumber默认callback）、NULL/typed/zero/multiple及原释放路径，必要共享helper按明确影响范围冻结，保留旧准入守卫。请作者和独立Sol以官方API/本机SDK复核这条实质兼容路线，而非再仅新增失败码。
