# F-20261012-077: macOS AXTextArea format metadata

The sixth native patch exposes format counts for the exact, pre-normalized CFString read from a non-web macOS `AXTextArea`. It reports UTF-8 byte count, Unicode code-point count, LF count, trailing LF count, and CR count when the string is at most 16 KiB. Larger values report only `source: ax-cfstring-v1` and `status: over_limit`. This describes the AX value read, not saved-file bytes or disk verification. The existing text value, trimming, labeling, and action semantics are unchanged.
