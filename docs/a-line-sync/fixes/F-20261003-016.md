当前GLM已支持low/high/max。Host缺省enabled只启用思考，省略reasoning_effort；[官方模型卡](https://huggingface.co/zai-org/GLM-5.3-Flash/blob/main/README.md)记载省略时默认max，但不证明当前网关遵循此默认，也不证明这是超时根因。
