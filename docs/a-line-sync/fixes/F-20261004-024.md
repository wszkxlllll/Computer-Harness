## 根因与修正

F023/I0412证明普通serve虽可指定socket，仍读取旧config/history并经过权限/遥测等前置入口。仅给serve加条件或过滤完整工具列表不足以消除副作用。

1. macOS main第一步识别`topology-readonly`与`topology-readonly-call`，早于history purge、内部worker、logging/telemetry、权限host、普通CLI与完整SDK。模式词错位、重复或参数不合法直接失败，不退回旧入口。
2. 服务端只构造core ToolRegistry并注册两个真实生产拓扑工具；不注册输入、截图、browser/profile/history/录屏工具，不初始化AppKit、PiP、overlay、更新检查或自动OS权限流程。core的空录制/session内存状态不启动截图。
3. 启动显式绑定正i32 PID和完整正u32 window ID；不同目标、工具、额外字段、内部session参数在AX/CG查询前拒绝。仅允许metadata/call协议方法，无shutdown/revoke或默认服务转发。
4. 保留standard及canonical authorization/policy/hard invariants；私有policy仍受显式managed deny约束。拒绝bypass/unrestricted/approved-manifest和内部worker等冲突环境。private observation在standard下为Routine，不承诺每次弹审批卡。
5. 私有绝对目录要求同UID、0700、非symlink及可信祖先；只读取显式根中的私有policy，不读取旧配置/history/PiP或fallback，不改HOME/PATH。socket/PID固定在私有根，已有文件拒绝覆盖。
6. 缺AX信任只返回固定失败码，不弹授权窗口或要求录屏。参数、策略与路径验证先于AX信任检查。
7. 专用客户端同样前置分流，验证只读mode、协议版本、根inode/UID、daemon PID、精确目标，以及请求前后endpoint一致性。拒绝缺失、unknown/error、错误版本和假成功响应；只输出固定数字/布尔/闭合枚举诊断，不输出原始text/rows/私人额外字段。
8. 串行查询，请求帧上限4096字节，服务端读写5秒界限，无重试/重放。退出或失败不自动unlink，以避免检查与删除之间的路径替换竞态；保留私有产物，每次启动使用新的私有根。

审查过程中实际修正：普通客户端启动副作用、握手只解析不验证、模式词错位回落旧路径、空/unknown响应误计成功、原样输出任意结构字段、自动unlink竞态，以及真实AX/CG原因白名单遗漏。
