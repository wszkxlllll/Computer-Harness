## 信任与链接合同

固定 profile 不允许 manifest 减少必需文件、重复条目、替换路径集合或使用 traversing/absolute 文件条目。ws packageRoot 是外部清单指定的规范相对物理目录，不从源码 pnpm 布局猜真实 staging 位置。5 个链接必须是实际 symlink，并 canonical 绑定 root 内指定 package 目录或该 ws packageRoot；不是仅存在 node_modules 字样。

root 明确：规范相对限制适用于 manifest 条目和 ws packageRoot，历史实际 symlink 的文字可以 absolute 或 relative，包含 `..` 亦可，只要 canonical 终点严格符合绑定。独立正反例已覆盖这个兼容边界，不把 root 内正确绝对 link 当成漏洞。作者补 readlink 与 dev/ino 前后检查、扫描末尾再核链接。静态预览中 localeCompare 与默认排序混用的问题已在冻结前统一为 ASCII 顺序；没有把该预览疑点记作本轮实际失败。

verify 要求外部 expectedManifestSha256 并先核 canonical manifest digest。它不验证谁提供 digest、签名或源码 revision 的来源；capture 输出加上自己刚算的 digest 不构成独立信任。两个输入须来自已审冻结来源，不能因为 API 接受字符串就声称 provenance 已认证。

## 证据与操作边界

普通文件和目录祖先不允许 symlink；O_NOFOLLOW、file handle stat、当前 path inode 与读前后元数据核对提供冻结候选的时点证据。它们不是原子 filesystem 锁，不能证明并发变更全部被阻止。ws 固定 19 文件不证明外部可选 bufferutil/utf8-validate 的解析环境。该 profile 也不代 Node 的真实 ESM 加载或服务账号读取测试。

本轮未读取真实 release 或共享 dist，没有 import server/index、listen、socket、HTTP、模型 API、配置或凭据读取、生产构建、部署、重启、桌面及 Git 操作。测试仅在 mkdtemp 的私有目录创建合成文件和链接，并由 fixture cleanup 删除这些精确自建目录；业务文件和持久运行数据未删除。文件清单通过不能代实际冷启动、运行内存版本、认证合同或 I002 验收。
