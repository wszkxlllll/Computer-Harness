## 范围与依据

T041–T043 的历史实际结果定位到 macOS 的 SDK 内部 ESM `loadSDK` 阶段；T043 私有错误上下文定位到 `@ubjs/core` 经 workspace 内 SDK alias 路径导入。静态拓扑显示 `packages/computer-cua/node_modules/@trycua/cua-driver-0.22.2` 是指向 pnpm store SDK 包的 symlink；store 包下 `node_modules/@ubjs/core` 存在，而 `packages/computer-cua/node_modules/@ubjs/core` 不存在。对 alias importer 与 realpath importer 的只读解析结果不同，支持 canonical entry 是一个待验证候选，但静态证据不证明其为实机根因。旧 T043 文件和记录不修改、不重跑。
