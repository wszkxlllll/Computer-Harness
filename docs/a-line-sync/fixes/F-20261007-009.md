只允许固定 `metadata` 与 `check_permissions` 请求，后者固定 `prompt:false`、`probe_direct_capture:false`；不接受任意工具或参数、不重试、不回退默认 socket。端点须为显式私有路径，核 canonical 路径、父目录和 socket 类型、权限、owner及设备/inode，前后变化立即拒绝。总截止最多30秒，使用单调时钟，取消、超时、过大或无效回复均关闭客户端并忽略迟到结果。合成测试仅注入 fake 文件系统、连接和时钟，不创建真实测试服务。

socket 文件元数据、daemon 自报 PID 及权限 `source` 的一致性只能提供关联线索，不证明 peer 身份、TCC责任归属或系统设置中的具体应用。任何结果都保持 `readyForDispatch:false` 和权限归属未确认，不能产生 F008 pass/token。读取客户端关闭也不等于远端 daemon 已退出。
