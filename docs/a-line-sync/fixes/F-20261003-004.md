## 根因与修正

实机原轨迹的 drag 106/216 → Host window-pixel 81/165 → driver screen 62/138，与源码重复缩放一致。CUA 0.22.2 macOS 接受 get_window_state 返回PNG的像素；驱动自行恢复截图缩小比例及Retina比例，再叠加屏幕原点。Host预先乘bounds/viewport导致第二次缩放。五次失败点击含DOM及映射到DOM的UIA路径；completed回执不是实际落点证明，原焦点保护使本次零文本输入。

独立证据：本机安装0.22.2原生库工具schema（只读strings，未执行driver），以及官方固定tag `cua-driver-rs-v0.22.2`、commit `d114f35fec05ecd37bf529e5587be86852205b64`：

- [click.rs](https://github.com/trycua/cua/blob/cua-driver-rs-v0.22.2/libs/cua-driver/rust/crates/platform-macos/src/tools/click.rs)：截图像素接口。
- [get_window_state.rs](https://github.com/trycua/cua/blob/cua-driver-rs-v0.22.2/libs/cua-driver/rust/crates/platform-macos/src/tools/get_window_state.rs)：原图/返回图比例登记。
- [drag.rs](https://github.com/trycua/cua/blob/cua-driver-rs-v0.22.2/libs/cua-driver/rust/crates/platform-macos/src/tools/drag.rs)、[px_frame.rs](https://github.com/trycua/cua/blob/cua-driver-rs-v0.22.2/libs/cua-driver/rust/crates/platform-macos/src/tools/px_frame.rs)：恢复缩放及像素到屏幕点转换。

修正仅macOS直接派发截图像素，保留Windows/Linux历史转换。若执行前的新观察与决策截图尺寸不同，坐标动作拒绝 `WINDOW_VIEWPORT_CHANGED`，要求重新定位；不影响无坐标的键盘操作。越界、窗口几何、foreground、输入焦点和未知结果不重放规则保留。

P1：hybrid degraded且没有DOM候选时明确提示等待页面就绪，使用可用wait后取得自动新观察，不猜页面原点、不用drag代替点击。未延长3.35秒采样预算、未猜contentRect，首次AXWebArea就绪原因仍需实机诊断，不宣称根治或API速度改善。
