# 作品提交材料

作品采用Lightspeaker产品名与Computer Harness技术内核名，申报“开源赋能的AI应用创新”，结合开源项目改进与生态贡献。这里集中准备提交内容，不作为普通用户使用指南。

## 现在可以审阅

- [技术报告正文](./technical-report.md)：按九章组织，包含系统架构和执行流程图，展示六类真实任务内容及代表性跨应用流程，不编总体成绩或性能收益。
- [独立第三方资源清单](./third-party-resources.md)：供附件编排，关联仓库许可声明；尚需完成具体发行物及服务条款核对。
- [真实生活案例](../real-task-cases.md)：供报告及Demo选材，历史题卡与运行证据已下沉。
- 项目[LICENSE](../../LICENSE)与[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 提交前待完成

| 材料 | 具体动作 |
| --- | --- |
| 报名字段 | 队长核对团队名称/编号、成员和作品名，简介按系统限制填写；不在公开文件写私人联系方式 |
| 报告终稿 | 审正文和图，补正式Demo的访问方式与必要产品截图；确定提交版源码及driver来源后导出PDF，检查匿名与元数据 |
| 正式Demo | 用户准备干净初态后重录手机和电脑，保留真实语音、确认、跨应用过程及最终消息；等待加速注明，原片留存 |
| 可运行版本 | 固定源码/锁文件/模型与driver配对；Windows另一台电脑按集中指南冷启动，Mac由队友补完整流程及实机记录 |
| 第三方附件 | 在冻结版本生成完整传递依赖清单，核实际驱动及平台binding的LICENSE/NOTICE；服务条款和展示素材另核，不上传密钥/profile |
| 成果入口 | 确认仓库、发行物、报告和视频在评审期可访问；若提供受控体验，使用隔离Host和测试账号，不把个人Preview开放为任意人控制 |
| 开发与授权 | 依据真实commit/PR说明团队与AI辅助开发；核共同权利人授权，准确标记上游PR状态 |

当前交付的是可审阅报告正文，不是已提交的PDF或最终视频。没有要求团队为填表补造用户数据或强行新增实验；实际功能、来源、版本与自主边界仍需准确。

## 格式与核对依据

按2026-10-20已核的[AIC主题赛要求](https://www.aicomp.cn/tracks/tracks-5/4924.html)及[赛程调整通知](https://www.aicomp.cn/notice/notice-3/5435.html)：报名、缴费、初赛提交截止2026-10-30 20:00。作品名不超过20字，简介不超过300字；报告PDF不超过10MB，正文建议15页以内，第三方清单可作附录；视频MP4为3—5分钟、不超过300MB。决赛PPT以后续通知为准。

报告、视频与PPT检查学校/指导教师标识和私人信息，同时保留适用的第三方署名。报名系统中的实际字段、文件限制及补充通知由队长提交前复核。公开在线无限额服务不是本轮核到的硬要求，但成果必须能访问和核验。

历史材料规划与逐轮安排保存在[历史目录](../history/README.md)，不再作为当前任务分工或另外一份技术报告。
