## 格式与核对依据

按2026-10-20已核的[AIC主题赛要求](https://www.aicomp.cn/tracks/tracks-5/4924.html)及[赛程调整通知](https://www.aicomp.cn/notice/notice-3/5435.html)：报名、缴费、初赛提交截止2026-10-30 20:00。作品名不超过20字，简介不超过300字；报告PDF不超过10MB，正文建议15页以内，第三方清单可作附录；视频MP4为3—5分钟、不超过300MB。决赛PPT以后续通知为准。

报告、视频与PPT检查学校/指导教师标识和私人信息，同时保留适用的第三方署名。报名系统中的实际字段、文件限制及补充通知由队长提交前复核。公开在线无限额服务不是本轮核到的硬要求，但成果必须能访问和核验。

历史材料规划与逐轮安排保存在[历史目录](../history/README.md)，不再作为当前任务分工或另外一份技术报告。
