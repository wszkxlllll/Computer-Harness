Lightspeaker 是一个连接手机与电脑的生活任务智能体。你说明想做什么，它在真实网站和桌面应用中执行；你可以查看画面、听取进展、补充要求，在关键步骤作出决定。

**让 Agent 适应不同使用者，而不是要求使用者适应 Agent。**

## 生活里的事，不必困在复杂界面里

“帮我比较明天上午的两班直达车，把乘车信息整理好发到文件传输助手。”

一个简单需求，往往意味着找入口、核对条件、反复切换应用、整理信息与交付结果。Lightspeaker面向这样的日常任务：从政务办事、就医准备、购物售后，到出行票务、社区服务、通信与个人事务。浏览器与桌面应用是完成任务的工具，而不是把用户困住的边界。

## 轻松托付 · 全程知情 · 关键把关 · 隐私有界

|  | 为使用者带来什么 |
| --- | --- |
| **轻松托付** | 手机输入或语音交代需求；大字显示、读屏交互与个性化偏好，让不同使用者以熟悉的方式参与。 |
| **全程知情** | 查看实际截图、任务进度与结果；听取进展播报，随时补充条件、纠正方向，不必只等一个结束通知。 |
| **关键把关** | 风险扫描和审批接入执行流程；在需要确认时由你决定，也可以暂停、纠正或停止后续操作。 |
| **隐私有界** | 明确选择操作范围，按配置采集视觉与控件信息；受管浏览器登录状态保留在电脑，任务中的数据流向与授权边界明确可查。 |

这些设计面向每个希望减少操作负担的人，也关注老年人、低数字素养和视障用户的使用需要。科技的便利，应当包含更多人的参与方式。

## 可靠执行，源自 Computer Harness

Lightspeaker 的技术内核 **Computer Harness**，承接模型决策与真实桌面执行之间的状态、控制和恢复。

### 跨应用，任务不断线

同一任务保有稳定的 ComputerSession；Surface Registry 跟踪实际使用的窗口与页面、引用新鲜度及有可靠关系证据的子界面。应用切换与界面变化成为可处理的执行过程，而非重新开始任务的理由。

<!-- Surface Registry 示意图：稳定Session、显式切换、引用失效及重新观察。 -->

### 有回执，也有再观察

**观察 → 决策 → 准入 → 执行 → 回执 → 再观察 → 结果核对**

统一工具注册、动作预算、失败传播与运行轨迹，让系统区分“请求了什么”“执行了什么”和“观察到什么”。结果未知时不自动重放可能已发生的操作，纠正与审批始终属于同一个 Run。

<!-- Runtime执行闭环图。结果核对不表示具有通用自动业务验证器。 -->

### 一套内核，多种选择

Provider、Computer、Context、Planning 与 Run Memory 通过组件装配协作。Windows与macOS复用公共合同，平台输入和窗口机制分别适配；视觉操作与可选UIA、受管浏览器DOM相辅相成。

模型负责理解和决策，CUA提供底层观察、输入及窗口能力；Computer Harness实现其上的任务运行、执行控制、状态管理与人机协作。[了解系统设计](./docs/ARCHITECTURE-AND-COMPOSITION.md)。

## 开始使用

**电脑执行，手机掌握。** 手机使用Web界面，无需安装原生App。

1. **准备电脑。** 按[安装与配置指南](./docs/getting-started.md)准备Node.js、pnpm、匹配的CUA驱动及模型凭据，完成本机配置。当前产品面向Windows和macOS。
2. **连接手机。** Windows用户在已完成配置的仓库根目录运行下方命令；按[手机指南](./docs/mobile-control-guide-2026-09-26.md)连接HTTPS Relay并扫码配对。macOS按平台指南准备权限和启动Host。
3. **交代任务。** 准备所需应用或网站登录状态，输入目标；在手机查看过程、补充条件并处理审批。

```powershell
.\scripts\mobile.ps1 start -Build
```

需自备模型服务凭据；跨设备使用需可访问的HTTPS Relay，部署见[Relay说明](./apps/relay/README.md)。本仓库不提供个人账号、登录profile或公共无限额控制入口。

## 使用与数据边界

窗口范围与全桌面模式具有不同采集范围；全桌面执行共享前台输入，运行期间不要同时操作鼠标键盘。窗口范围不等同于操作系统沙箱。

任务文本、截图及必要上下文可能发送给所配置的模型，语音识别使用第三方服务；受管浏览器DOM不等于访问任意个人浏览器。Guard与审批不能撤销已经发生的操作，请仅在有权操作的账户和资料上使用。
